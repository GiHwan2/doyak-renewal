프로젝트 소개

커넥트인 애드는 AI 기반 옥외광고 전용 실시간 모니터링 및 성과 분석 솔루션입니다. 데이터 기반의 매체 설정과 타겟팅으로 캠페인을 기획해 운영하고, 광고주 전용 대시보드를 통해 실시간 현황을 관리하고 GPS 데이터와 유동 인구 및 교통량 데이터를 활용해 광고 성과를 분석할 수 있습니다.

프로젝트 목표

광고 기획부터 실행 및 사후 관리까지 전 과정을 서비스 기반으로 운영할 수 있도록 설계했습니다. 광고 매체와 지역을 자동 설정하고, 현황과 성과 지표를 실시간으로 모니터링할 수 있는 화면을 설계해 데이터 기반 의사결정을 돕는 것을 목표로 했습니다.

AI 기반 광고 기획안 자동 생성

예산과 타겟, 업종 정보를 입력하면 유동인구·소비패턴 데이터를 분석해 최적의 매체와 지역을 자동 매칭하는 화면을 설계했습니다. 추천 지역과 예상 도달율·노출수를 카드형 UI로 정리해 결과를 한눈에 파악할 수 있게 만들었습니다.

실시간 대시보드로 광고 현황·성과 관리

캠페인의 매체 위치와 노출 상태를 지도에서 실시간 모니터링할 수 있는 대시보드를 구축하고, 노출 수·도달율·CPM과 지역별 히트맵을 함께 보여주는 성과 분석 화면을 설계했습니다. 시간대·성별 타겟 데이터도 한 화면에서 비교할 수 있게 구성했습니다.
