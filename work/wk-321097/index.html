프로젝트 소개

제휴 숙박업체를 승인된 회원만 예약할 수 있는 회원 전용 예약 플랫폼입니다. 회원이 웹이나 앱에서 숙소를 골라 예약을 신청하면, 운영사 관리자가 관리자 웹에서 바로 확인하고 확정합니다. 위시켓 공고에 지원하며 서비스 이름(누림스테이)과 데이터를 가상으로 정해 직접 기획·디자인·개발한, 실제로 눌러 볼 수 있는 데모입니다.

프로젝트 목표

회원 웹, Android·iOS 앱, 관리자 웹이 하나의 데이터로 이어지는 구조를 만듭니다. 가입 승인, 숙소 조회, 예약 신청·확정·취소, 리뷰, 배너, 통계를 꼭 필요한 기능만으로 구성합니다. 관리자가 개발 지식 없이 숙소·객실·배너를 직접 등록하고 관리할 수 있게 합니다.

승인 회원 전용 숙소 탐색과 예약 신청

지역 필터와 예약 가능 숙소 보기로 제휴 숙소를 찾고, 결제 없이 일정·객실·인원만 골라 신청합니다. 마감 객실은 선택할 수 없습니다. 가입 신청, 관리자 소속 확인, 승인·반려, 승인 알림까지 회원 화면과 관리자 화면을 하나의 흐름으로 설계했습니다.

관리자 예약 확정과 회원 앱 즉시 반영

관리자 웹 예약 표에서 신청 건을 확정·변경·취소하면 회원 앱의 예약 상태와 알림이 같은 데이터로 바로 바뀝니다. 예약대기·예약확정·이용완료·예약취소 상태와 상태별 처리 버튼을 회원 앱과 관리자 웹이 같은 데이터로 쓰도록 구현했습니다.

운영 지표 대시보드

확정 대기 예약, 가입 승인 대기, 월 예약 신청, 배너 클릭률과 기간별 그래프를 한 화면에서 보고 바로 처리합니다. 관리자 웹에서 객실 예약 받기와 배너 노출·순서를 바꾸면 회원 화면의 마감 표시와 홈 배너에 곧바로 반영되게 했습니다.
